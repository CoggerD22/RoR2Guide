Files starting with `_` are **not published** — copy this to
`content/guides/my-guide.md` and edit.

This is the opinion layer. Subjective content is allowed here and **only** here:
build advice, item priorities, tier takes. It is always badged "Opinion", always
stamped with the author, date, and game patch above, and it never leaks back into
`items.json` or the codex (CLAUDE.md rule #7).

If `patch:` stops matching the dataset's current content version, this guide
automatically shows a "written for an older patch" banner — so opinions age
visibly instead of quietly rotting.

## Writing notes

- State mechanics as facts and link them; save judgement for the recommendation.
- Prefer "why" over "best": *Crowbar multiplies damage above 90% HP, so it favours
  one-big-hit kits over sustained fire* is more useful than *Crowbar is S-tier*.
- Numbers belong in the datasets. Quote them here, don't redefine them.
